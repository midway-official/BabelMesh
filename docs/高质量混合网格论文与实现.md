# 高质量混合网格：论文依据、实现选择与验证

检索与复核日期：2026-10-12。引用作者原文、论文预印本和出版社记录。论文中的质量和性能属于其算法及算例，不能直接作为 BabelMesh 的验收结果。

## 原始文献与实现选择

| 文献 | 有用的方法 | 本轮选择 |
|---|---|---|
| Klingner & Shewchuk, *Aggressive Tetrahedral Mesh Improvement*, 2007，[作者论文](https://people.eecs.berkeley.edu/~jrs/papers/aggress.pdf) | 顶点平滑与局部拓扑变换互相补充，扩大可以改善的局部状态。 | 限定使用不增加单元的 3→2、4→4 内部换边，保持空腔外表面；没有实现论文全部算子。 |
| Marot & Remacle, *Quality tetrahedral mesh generation with HXT*, 2020，[原文](https://arxiv.org/html/2008.08508v1) | 组合平滑、边删除和空腔重构；固定点分布有助于维持尺寸场。 | 受约束平滑、少量换边、按新邻接再平滑；用 CFD 面指标决定接受。没有实现 Growing SPR Cavity 或并行 HXT。 |
| Gao, Yu & Holst, *Quality Tetrahedral Mesh Smoothing via Boundary-Optimized Delaunay Triangulation*, 2012，[作者全文](https://ccom.ucsd.edu/~mholst/pubs/dist/GYH11.pdf) | ODT/B-ODT 优化顶点位置，并处理边界、体积和尖锐特征保护。 | 保留原有体积加权四面体外心目标，只用于内部过渡点。物理壁面、层带和笛卡尔点固定；不是完整 B-ODT。 |
| Knupp, *Algebraic Mesh Quality Metrics*, 2001，[出版社记录](https://epubs.siam.org/doi/abs/10.1137/S1064827500371499) | 归一化代数度量描述单元形状，均比与条件数有关。 | 增加四面体均比和分区域统计；不替代 BabelSim 面质量门槛。 |
| Marcon 等, *High-order curvilinear hybrid mesh generation for CFD simulations*, 2018/2019，[预印本](https://arxiv.org/abs/1901.00992) | 贴壁棱柱/六面体组织高伸长率层带，与远场四面体衔接，独立控制层厚和角区。 | 参考薄层设计。本工程仍按当前约定：二维挤出三棱柱，三维层带四面体；未改成论文的棱柱方案，未实现高阶单元。 |

## 采用的流程与约束

完整笛卡尔背景和局部加密 → 挖除并预留空腔及层带 → 提交指定高度的层带 → 受约束贴体填充。优化在共享面、正体积和闭壳检查之后执行。

1. 固定背景、物理边界和标记的边界层节点。二维前后点成对移动，不能产生四面体或第二个厚度层。
2. 尝试邻接平滑、体积加权外心目标、面中心对齐及有限局部移动；缩小步长后重新检查。
3. 默认启用 `optimization.topology_swaps`。只处理完全由三维过渡四面体组成的内部边星。3→2 减少一个单元，4→4 保持单元数；不添加节点。原空腔皮肤保持不变。
4. 先比较局部面惩罚，再检查完整网格。必须保持空腔体积、共享面方向、正体积、凸壳和固定域边界。四项全局 max/p99 面指标均不得恶化，组合目标必须下降。
5. 接受换边后重建邻接，再执行至多两轮受约束平滑。换边至多进行 `min(256, iterations * 32)` 次完整候选检查，记录实际尝试和接受次数。

凸多面体合并由 `optimization.merge_transition_cells` 单独控制，默认关闭。缺失区域标签的外部输入固定全部节点和单元，不推测未知层带后移动。优化实际新增节点和单元恒为零。

固定背景/计算域是独立硬约束。所有输出顶点必须位于声明的闭区间内，越界候选回滚。显式单位缩放同步缩放坐标和锁定边界。

## 报告与独立验证

`mesh_report.json` 提供全局最大值和 p99；面门槛仍为非正交角 75°/60°、内部偏斜 0.5/0.25，未放宽。

- `region_face_quality` 分背景、层带、过渡区统计；跨区域面计入两侧，帮助定位根因。
- `tetrahedron_shape_quality` 报告最小、p01、中位均比：`12*(3*V)^(2/3)/sum(edge_length^2)`。正四面体为 1，接近 0 表示扁薄；这是诊断，不是新增 CFD 通过门槛。
- 优化前后指标、换边数量、位移、单元数和边界审计单独记录。真实 BabelSim reader 核对面几何。

回归固化两个内部空腔：3→2 降低偏斜并减少一个单元；4→4 保持节点、单元数、边界和体积，跨过原先未通过的面门槛。检查关闭换边、保护层带和非法参数类型。最终同参数整网格对比见 [交付验收](../acceptance/HYBRID_REWRITE_20261012.md)。

## 薄四面体层和参数选择

以下是结合文献与本工程实测的判断，并非通用的充分条件：

- 切向表面尺寸与法向首层高度应共同设置。法向很薄、切向很粗时，保持层高的四面体仍可能有较高非正交角。不能放宽门槛或改变层高来宣称达标。
- 过渡尺寸逐步接近背景间距；尺寸源的 `transition_width` 缓和突变。背景 2:1 平衡有助于连接，但不保证贴体面质量。
- 首层厚度来自物理近壁分辨率，不等于首排单元中心壁面距离。先定层高，再查看层带和过渡区独立统计。
- CAD 容差与表面尺寸分开。收紧容差可能增加表面和层单元，受尺寸下限、单元数和内存预算限制。

尚未实现复杂层终止、全局交叠扫描、一般空腔搜索、各向异性度量优化、曲面边界滑移或完整 B-ODT。三维薄层仍可能未通过严格门槛；局部改善不能代替整网格验收或 CFD 物理验证。
