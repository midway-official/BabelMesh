# M4 网格质量整改方案（公开资料与当前证据）

日期：2026-09-23。本文是 M4 失败分析与下一轮实施/验收顺序，不代表整改已完成，也不改变既有验收阈值。

## 当前证据说明

当前生成器先对 3D 笛卡尔背景网格做 CAD 交切区细化，再做 seed 连通域提取和表面贴合。这种 hex-dominant 路线合理，但曲面贴合会遇到初始网格连接关系的限制。M4 锁定门槛包括零非法单元、正则 hex 最小 scaled Jacobian ≥0.1、非正交度 max/P99 ≤75°/60°、内部 skew max/P99 ≤0.5/0.25，以及双向几何偏差和拓扑有效性；判据见 `quality/profiles/strict-cfd-v1.json` 与 `docs/BabelMesh-开发Prompts.md`。

历史保存的球体失败样本（半径 0.7、8³ 根网格、表面尺寸 0.015625、4 层自适应）由独立 VTU 角 Jacobian 检查得到 131,046 个 hex 中有 16,808 个低于 0.1，且这 16,808 个都是真负 Jacobian；非正交 max/P99 为 81.0015°/76.8256°，超过门槛。坏 hex 与球面壁面的关联统计是：其中 11,544 个单元有 2 或 3 个球面边界面，另有 5,264 个只有 0 或 1 个球面边界面。说明球面处多个面被压向同一曲面是主要触发模式，但并非唯一问题，内部位移传播也需单独分析。样本及脚本位于 `acceptance/evidence/m4-sphere-quality-failure/` 和 `acceptance/evidence/m4-acceptance-20260923/sphere-topology.json`。

2026-09-23 初次验收发现：当时源码在面合并阶段把映射 Jacobian 小于 0.1 的单元标为 polyhedron。该缺陷随后已修复，并有低 Jacobian hex 保持可见的回归；以下保留原始缺陷证据。一个独立复现把剪切立方体的 hex Jacobian 从 0.04994 降至不达标，同时在无任何面合并、点坐标不变时仅取消该 hex 标记，结果报告中的剩余 hex 最小 Jacobian 变成 1。证据见 `acceptance/evidence/m4-acceptance-20260923/relabel-probe.log`。这不是质量改善，质量审计必须报告真实类别与所有低质量单元；坏 hex 只有在确实重连为合法 polyhedron、重算体积和面质量后，才能作为 polyhedron 重新评价。

## 公开资料所支持的方法

- OpenFOAM 官方 `snappyHexMesh` 文档把曲面贴合分成网格平滑、向目标曲面/特征移动、质量检查和回退重试。违反门槛时撤销或缩短点位移，接受一定几何贴合损失；它还将普通曲面吸附和特征边吸附分别处理。这支持“每步候选均过门禁、回退必须原子化、面/棱/角采用不同几何约束”的设计。[Snapping](https://doc.openfoam.com/2306/tools/pre-processing/mesh/generation/snappyhexmesh/snapping/)；[Mesh quality](https://doc.openfoam.com/2212/tools/pre-processing/mesh/generation/snappyhexmesh/meshquality/)
- Sandia CUBIT/Sculpt 资料指出，普通平滑有时不能解决坏 hex，需要先改变周边 hex 拓扑，例如在曲面或特征附近 pillowing 插入一层过渡 hex，再进行平滑；它还使用从全域 Laplace 到局部优化的分层平滑，并以 scaled Jacobian 识别劣质 hex。[Mesh Improvement](https://www.sandia.gov/files/cubit/15.6/help_manual/WebHelp/mesh_generation/meshing_schemes/parallel/sculpt_improvement.htm)；[Sculpt Smoothing](https://www.sandia.gov/files/cubit/15.5/help_manual/WebHelp/mesh_generation/meshing_schemes/parallel/sculpt_smoothing.htm)
- 一项 2024 年公开 hex 优化研究使用混合 Jacobian 与 scaled-Jacobian 目标、增强拉格朗日约束、L-BFGS 和 Armijo 线搜索；表面点保留在输入表面，棱点限制在特征线上、角点固定在角点。[HexOpt 论文](https://arxiv.org/abs/2410.11656)。这为后续局部约束优化提供具体算法候选，但不是可以直接声称已实现的现有功能。
- CGAL 官方文档把三角面片的自交检测、尖锐特征识别、各向同性表面重网格和有界误差 Hausdorff 距离分别提供。其有界误差距离支持双向估算，并通过细分与 BVH 给出误差界，适合作为 CAD 三角化表面几何验收的参考实现。[CGAL PMP](https://doc.cgal.org/latest/Polygon_mesh_processing/index.html)。
- Cadence 官方公开材料确认 HEXPRESS 支持 volume-to-surface 与 surface-to-volume、自动表面捕捉、边界层和网格优化；公开信息并未完整披露 HEXPRESS 私有内核，因此本方案只借鉴流程思想，不宣称复刻其专有算法。[Cadence HEXPRESS overview](https://www.cadence.com/en_US/home/tools/system-analysis/computational-fluid-dynamics/pre-processing-meshing.html)。

## 按优先级实施

### P0：先让质量门禁不可绕过

1. 从 `consolidateCoplanarFaces` 删除“scaled Jacobian 不达标就清除 `strict_hex`”的质量驱动分类。拓扑类型由实际面环和连接关系决定，质量差异不能更改类型标签。
2. 对输出中每个 `VTK_HEXAHEDRON` 独立重新计算全部 8 个角 Jacobian，与生成器内部报告交叉比对。任何低于 0.1 的 hex 都是失败，不能用 polyhedron 标签逃避。若显式执行 edge split / face split / cell reconstruction，则记录前后单元、拓扑变更、质量与体积守恒。
3. 对 polyhedron 检查闭壳、流形边、面朝向、正体积、面扭曲、非正交度和 skew；不能因通用多面体没有 hex Jacobian 就跳过质量门禁。
4. 每次贴合尝试保存并恢复点、面、单元类型、patch 和尺寸场的完整快照。失败回滚后逐字节或容差核验拓扑和坐标没有残留变更。

验收：人为构造剪切/翻转 hex 时，门禁必须失败；只有显式记录的拓扑重构后并通过 polyhedron 全套门禁才可接受。门禁报告列出差单元 ID、8 个角 Jacobian、位置及邻接壁面。

### P1：球面及旋转盒先做拓扑条件化贴合

1. 在最终点移动前，将 CAD 面、锐边、角点和薄壁两侧建立显式关联。球面点沿面移动；几何锐棱上的点约束到对应 CAD edge；角点约束到 CAD vertex。两侧薄壁保存不同的面关联，禁止仅按最近距离跨壁跳转。
2. 对每个待贴合边界单元构造局部风险指标：一个 hex 有几个面属于同一曲面、哪些角点在同一 CAD patch、映射角 Jacobian、面/棱捕捉冲突。球体至少把历史坏单元的“同一曲面 2/3 面”模式做成有编号、可重复的触发分类。
3. 对高风险边界先作局部拓扑操作，而不是硬压多张六面体面到球面：优先尝试沿曲率和特征分布细化；其后尝试面/边重构或 pillowing 式缓冲层，使每个边界 hex 有可行的局部映射。单纯增加均匀全域分辨率会增加成本，不保证拓扑奇异消失。
4. 平滑或局部重构后用共享节点一次性贴合面，保持边界切向/法向约束；相邻面共享同一几何边的节点和分割。旋转盒平面回归必须维持现有通过表现，不得牺牲尖角/棱关联。

### P2：质量约束的分级平滑和优化

1. 在几何特征固定条件下，先做少量 Laplace 预平滑，平滑权重按边长与单元体积归一化；随后只优化低质量单元及一圈邻域，避免全域平滑拉动远场或稀释边界层。
2. 对规则 hex 用混合目标：最小化负/低 scaled Jacobian 惩罚，同时改善正交性、体积比、长宽比、扭曲度；采用线搜索，任何一步造成新反转或超过原几何误差容限立即拒绝。表面自由度限制在 CAD face，特征边点限制在 curve，角点固定。
3. 在可行域边缘使用局部加密、边分裂、pillowing 或 poly 重构；点位移优化不能修复错误连接。每次拓扑操作后重新计算闭壳、体积、全角 Jacobian、面指标与 CAD 距离。
4. 所有失败尝试需原子回滚，并记录尝试次数、步长、失败原因、局部最差单元和前后质量。达不到标准时应明确失败，不得把部分贴合网格报告为正式通过。

### P3：验证面内误差和整个网格

1. 对 CAD 曲面三角化网格执行 CAD→mesh 与 mesh→CAD 双向采样；采用曲率/局部尺寸自适应采样并报告采样密度、最大值和分位数。顶点投影误差小不代表面中部误差小。
2. 以空间索引对不相邻单元做潜在相交筛选，对候选面/体执行稳健三角相交检查；单独检查边界闭合、非流形、重叠单元、内部面 owner-neighbour 投影符号。
3. 报告 cell-count 和体积加权的质量分布、最差单元 ID/中心、边界面 ID/CAD patch、拓扑类型、采样误差、单元体积比与回滚次数。
4. 在球体和圆柱上做粗/中/细三档分辨率试验：中档体积误差 ≤0.5%，随分辨率加密体积误差与曲面误差均应收敛。旋转盒测试保护平面特征结果。补齐圆角台阶、有限厚尾缘、夹缝、外域减物体。
5. 每个接受网格必须由真实 BabelSim reader 读取并 validate，并由独立脚本复算 hex Jacobian；生成器自报成功不能作为唯一证据。

## 当前建议的修复顺序

先做 P0，避免质量指标漏报；然后针对球面坏单元做 P1 的拓扑分类与最小化重现，比较“增加局部细化”“曲面 pillowing/局部面重构”“只做受约束优化”三种候选。每种候选都保留同一 CAD、同一 size field、同一 solver reader 和严格门槛，逐步做 A/B。P2 平滑只能在 P1 改善了可行拓扑后处理。最终同时通过旋转盒与球体，才能把优化记为 M4 进展；完整 M4 还需完成本文件 P3 的必需几何和完整质量审计。


## 2026-09-24：网格分辨率与贴合误差分开设定

贴体尺寸与 CAD 拟合误差是两个独立约束：`sizing.surface_size` 是 CAD 邻域单元边长上限（按项目长度单位输入），`quality.max_surface_deviation_m` 是几何拟合容差（米），不决定单元数量。先按表面/局部尺寸场细化、裁切和分割，再 snap 与内部质量优化，最后做 CAD→网格及网格→CAD采样检查。球体当前案例用 1 mm 拟合容差和 15.625 mm 表面目标边长时仍得到合格面/体质量。

当前 `OctreeForest` 每次分裂全部三轴，因此已移除看似支持独立轴向尺寸的 `surface_size_xyz` 配置，改为与算法相符的单个各向同性 `surface_size`。如后续需要切向/法向或 x/y/z 各向异性尺寸，应先实现方向性 box-tree split、各向独立 level、邻接平衡与共享子面拓扑，再开放相应配置。

本轮的双向误差模块按指定间距采样 CAD 三角化曲面和网格边界三角面，CAD样本投影回精确B-Rep。它报告的是采样距离，不是连续 Hausdorff 误差上界；B-Rep 网格挠曲由 CAD 三角化 deflection 另行报告。自交/重叠仍需单独的三角/体相交检查。

## 当前实现流程核对（2026-09-24）

1. 项目 JSON 指定计算域 bounds、背景 `cell_counts`、`sizing.max_level`、`minimum_size`/`maximum_size`、尺寸源和资源预算。程序先从背景笛卡尔六面体建立 OctreeForest。`max_level` 决定最大可达细化层级；CAD 边界用显式 `surface_size`，CAD相关项目不得静默继承 `minimum_size`；各局部尺寸源用自己的 `target_size`。所有活动约束中最小的目标尺寸控制细化，`minimum_size` 是硬下限，Octree最大层级、cell及内存预算共同限制可行域。
2. 区域加密支持 box、sphere、cylinder、CAD group / distance / curvature 和 gap 尺寸源。CAD 与 gap 候选有边界盒筛选及 OCCT 精确距离；曲率目前以修剪 CAD 面的 3×3 UV 采样估计。`curvature.target_size` 只表示目标单元边长，`region.max_radius` 独立指定哪些曲面触发细化。Surface band 按 CAD BVH/AABB 与 fluid inside/outside/intersect/uncertain 分类，`surface_buffer_layers` 将命中查询盒按 `surface_size` 扩张，缺省2层。分裂全部 8 子 cell，之后作 2:1 邻接平衡。
3. `sizing.surface_size` 在 CAD snap 前给出表面邻域单元最长边上限。生成器在曲面缓冲带内约束八叉树 cell 的最长边不超过该值；这是八叉树特征单元尺度，不是边界三角面长度控制，也不是 CAD 离散弦高误差。由于只有 dyadic 层级，实际尺寸可能比该上限小一级；若这会低于 `minimum_size`，或最高层级仍不可达，则拒绝冲突输入。表面带与区域尺寸源重叠时取最细目标；严格模式还要通过 cell、内存预算。
4. 完成自适应网格后，M4 用 CAD 相交分类和流体种子 flood fill 选择流体 cell、形成 CAD 边界面。提取边界节点到精确 trimmed B-Rep face 的最近点，平面棱角节点保护 CAD 关联；对曲面节点作切向平滑并作CAD投影。外边界固定，以加权图 Laplace 位移传播至内部。严格模式分开调节 CAD boundary snap fraction 与核心形变 fraction；每轮计算 signed volume、采样贴合误差和质量，超限就降低回退比例。低 scaled Jacobian hex 可尝试实际拆成六个闭合面锥，但只有新拓扑全质量通过才提交。
5. 拟合容差由 `quality.max_surface_deviation_m` 指定（米），缺省为 `max(domainDiagonal*1e-4,1e-9)`，不依赖表面单元尺寸。它限制几何误差，不改变 surface refinement 的 cell-size criterion。严格 M4 之后对网格边界和 CAD 参考三角化表面做双向分层采样；CAD 样本投影到精确 trimmed B-Rep，并用网格三角形 BVH 求距离，样本间距取 `surface_size`，样本预算2,000,000/方向。该结果是离散采样误差，不是连续 Hausdorff 误差上界。当前该抽查超过容差会明确失败；它尚未驱动局部 snap 候选搜索，也不是自交/体重叠测试。

该参数分层参考 Hexpress 公开工作流：先设全局 Cartesian 初始单元尺寸，再对选定边界分别设 uniform refinement、edge-proximity 最小尺寸、曲率 divisions/minimum size、黏性层首层厚度/拉伸率/层数，生成后检查质量统计。公开资料没有给出其内部代码细节；本方案采用这些可观察的算法控制面，不声称复制商业实现。

## 2026-09-24：表面尺寸约束收敛

实现现将贴体表面分辨率明确为标量 `sizing.surface_size`：它约束 CAD 周围缓冲带中体网格单元的最长物理边；当前八叉树每次沿三轴平分，所以输入三组 x/y/z 数值既不产生独立网格密度，也不比标量更准确，已从 schema 和实现移除。CAD 贴合容差独立使用 `quality.max_surface_deviation_m`；缺省基于计算域对角线比例，用户可显式覆盖，但覆盖不改变单元密度。

约束优先级为：全局尺寸、表面尺寸和所有相交局部 size source 取最小活动目标；`minimum_size` 是自适应继续细分的硬下限（不回滚用户已经指定的背景细网格）；`max_level`、最大单元数和内存预算是硬可行性上限；CAD采样贴合误差及单元质量分别独立验收。CAD表面未显式给出 `surface_size` 时立即失败，不再暗中以 `minimum_size` 代替，防止无意生成过密网格。局部曲率源的 `target_size` 表示单元大小，`region.max_radius` 才是几何曲率半径筛选阈值。
