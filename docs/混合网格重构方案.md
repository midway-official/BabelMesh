# BabelMesh 混合网格与 Qt CAD 重构

日期：2026-10-09。范围：重做生成主流程、混合单元数据结构和图形界面，保留可用的 OCCT CAD 与历史验证资料。

## 需求与求解器契约

- 背景单元保持轴对齐的正交笛卡尔六面体，不再依靠拉动整个背景网格贴合 CAD。
- 二维是生成规则：对 CAD 做平面截面，在该平面生成笛卡尔四边形及贴体三角形，再沿指定厚度挤出一层六面体及三棱柱。最终仍输出三维体网格。
- 三维是生成规则：在 CAD 三角表面与笛卡尔核心之间生成四面体；六面体的四边形接口通过四棱锥连接到四面体。
- 边界层显式指定目标组、首层高度、层数与增长率。二维层带三角形挤出为三棱柱；三维层带按一致的面剖分生成四面体。不得将节点吸附误称为边界层。
- 最终输出 `BABELSIM_MESH 3`。每个共享面只有一个 owner 和一个 neighbour；边界面必须有物理 patch；前后面为 `symmetry`。求解器没有 `empty` patch 类型。
- 图形界面使用 Qt 6，提供 STEP 导入、参数化 CAD 操作、几何与网格视图、保存工程、后台任务和结果检查。界面与 CLI 共用核心。

上述二维规则依据 `../BabelSim/include/babelsim/mesh.h`、`src/io/mesh_reader.cpp`、`cases/naca0012/mesh_io.py` 与 `cases/planar_jet/generate_mesh.py`；本次不修改求解器。

## 新流水线

1. 校验工程配置、单位与资源预算，建立 CAD 流体域；先生成完整正交笛卡尔背景，按尺寸源加密并满足 2:1 邻接约束。
2. 对三维 CAD 表面或二维截面边界生成离散约束，并构造边界层预留偏移壳；此时不提交层单元。
3. 从已存在的背景中挖除实体内部、域外、层带与贴体预留区域。三维悬挂接口单元预留为混合过渡；二维保留有共线悬挂节点的多边形柱拓扑。去除非流形核心配置。
4. 完整覆盖的二维/三维 CAD 盒子边界（包括内流域）直接保留笛卡尔边界单元；覆盖不足或物理分组细分时使用完整 CAD 约束路径。核心节点始终固定。
5. 提交指定高度的层单元，检查方向、间隙和正体积。在挖出的空腔中用固定的核心接口及层顶面作约束，三维填四面体并用四棱锥连接四边形核心面，二维填三角形后统一挤出一层。
6. 建立唯一共享面，检查闭壳、边方向、边界归属、正体积和凸壳；可选优化只移动过渡区自由点，回滚质量恶化方案，新增单元数为 0。
7. 双向采样核对 CAD 误差，输出 BabelSim、VTU、检查点、质量报告及可选 Fluent ASCII/CGNS 文件。严格面质量失败不发布网格；报告区分拓扑、面质量与尚未完成的完整 CFD profile。

Gmsh 作为独立适配器中的受约束填充后端；BabelMesh 自己负责笛卡尔核心、CAD 操作、维数规则、层构造、拓扑合并、质量判断和求解器格式。Gmsh 官方手册明确支持离散实体以及通过四棱锥连接六面体和四面体，但这不等于任意复杂 CAD 自动满足 CFD 质量门槛。

参考：[Gmsh 手册](https://gmsh.info/doc/texinfo/)，混合六面体/四面体接口见 FAQ；离散实体见 `gmsh/model/addDiscreteEntity`。

## 工程与界面

新工程使用 `schema_version: 2` 和显式 `meshing.dimension`。二维还指定截面轴、截面位置和挤出厚度；所有保存的结果均为三维混合体网格。旧版工程仍能运行旧路径，便于保留已存在的验证边界。

Qt 主界面包含 CAD 操作树、交互视窗、网格参数和任务日志。CAD 操作以工程里的依赖关系保存，导入与操作编辑可以撤销/重做。生成在子进程中执行，界面保持响应并可取消任务。几何预览与网格预览必须来自实际核心输出。

## 验收顺序

1. 混合单元与唯一共享面：六面体、三棱柱、四面体、四棱锥的真实连接；拒绝重复、退化、开壳和非流形。
2. 二维外流圆柱及内流平面截面：背景保持正交，贴体区域确有三棱柱，前后面为 symmetry，只有一层厚度。
3. 三维球体、圆柱、布尔/STEP 几何：背景保持正交，贴体区域确有四面体，核心接口确有四棱锥，体积与边界一致。
4. 边界层：核对实际层数、首层高度、增长率、覆盖和正体积，并执行厚度冲突的负例。
5. 所有新网格通过真实 BabelSim reader；质量报告与该 reader 的几何结果交叉核对。
6. Qt 构建、打开/编辑/保存工程、CAD 预览、后台生成、结果预览与取消；检查实际渲染图像。

资源上限、输入失败、几何冲突和质量失败都必须保留明确诊断。编译、生成成功、reader 通过、质量门槛通过和复杂几何覆盖是分别报告的证据。
