# 混合网格参数与格式说明

新工程采用 `schema_version: 2`。可从 `examples/cylinder2d.json` 或 `examples/sphere3d.json` 开始，在 Qt 界面修改后保存；命令行读取同一工程文件。本文说明实际实现与当前限制，验收结果另见 [本轮验收](../acceptance/HYBRID_REWRITE_20261012.md)。

## 生成顺序与维数

1. 先生成完整笛卡尔背景，再执行局部 quadtree/octree 加密与 2:1 平衡。
2. 从 CAD 得到物理边界和边界层的偏移约束。
3. 挖除物体内部、域外、边界层占据范围及贴体/加密过渡预留区；检查保留核心的壳是否流形。
4. 提交指定高度的边界层，并在挖出的空腔填充贴体单元。
5. 建立唯一共享面、检查单元和边界，执行可选优化，再检查 CAD 距离。

笛卡尔核心节点始终固定。二维/三维 CAD 盒子边界被核心完整覆盖（内流或外流）且各面物理分组一致时，直接保留外边界六面体；覆盖不足或分组需要细分时使用完整 CAD 约束填充路径。报告记录是否保留以及原因。

二维在截面平面生成四边形和三角形，统一挤出一层体单元。四边形形成六面体，三角形形成三棱柱，带悬挂节点的多边形形成多面体柱。前后面为 `symmetry`，不使用 `empty`。二维不能包含四面体、四棱锥或第二层厚度。三维贴体与边界层使用四面体，四边形核心接口通过四棱锥连接。

## 单位、背景和加密

工程中的 CAD 坐标、网格间距和层高使用 `units.length`，支持 `m/mm/cm/inch`。内部网格和输出坐标统一为米。`quality.max_surface_deviation_m` 始终用米，与工程单位独立。STEP 的文件单位须与 `cad.imports[].length_unit` 一致；读入后归一化为米，导出的 STEP 写入米制单位。

| 参数 | 含义和约束 |
|---|---|
| `fluid_domain.mode` | `external`：外盒减去实体；`internal`：指定实体内部流体 |
| `background.bounds` | 三轴 minimum/maximum。外流工程应与 `fluid_domain.outer_bounds` 一致；内流工程应覆盖流体实体 |
| `background.cell_counts` | 每轴正整数分段数；每轴间距等于长度/分段数，不能大于 sizing.maximum_size |
| `background.cell_size` | 替代分段数的三轴最大间距；向上取整分段，真实间距可能略小。与 cell_counts 二选一 |
| `background.uniform_cells` | 新流程须为 true；局部自适应加密由尺寸源控制 |
| `meshing.dimension` | 2 或 3，描述生成规则 |
| `meshing.section_axis` | 二维截面的法向轴 x/y/z，沿该轴挤出 |
| `meshing.section_coordinate` | 二维截面位置，必须在背景范围内部 |
| `meshing.thickness` | 二维最终单层厚度；该方向的背景分段必须为 1 |
| `meshing.core_buffer` | 贴体空腔与核心之间预留距离系数；实际不低于 0.35，乘以所在背景单元最大边长 |
| `sizing.surface_size` | CAD 边曲线/表面离散的特征尺寸，不等于几何误差容差 |
| `sizing.volume_size` | 剩余贴体/过渡区域的目标尺寸；缺省使用 maximum_size |
| `sizing.minimum_size` | 加密尺寸下限；surface_size 和尺寸源目标不得低于该值 |
| `sizing.max_level` | 背景最大加密层级 0–20；不能通过忽略下限/层级满足不可达目标 |
| `sizing.balance_face_neighbors` | 必须为 1，对应 2:1 邻接约束 |
| `sizing.sources[].apply_to` | background、surface、transition 或 all；默认 all |
| `sizing.sources[].target_size` | 区域目标尺寸；重叠约束取最细有效目标 |
| `sizing.sources[].transition_width` | 区域外向常规尺寸过渡的宽度，非负 |

二维只在截面内细分，不沿厚度方向细分。三维粗细接口的悬挂单元预留为混合过渡区，减少粗细单元中心错位造成的偏斜。二维可保留有共线节点的多边形柱，输出环序须满足 BabelSim reader 的三角扇规则。

背景与计算域为固定边界：CAD 流体域不能超出背景；二维 `section_coordinate ± thickness/2` 必须在法向背景及外流计算域闭区间内。生成后的每个点和每个优化候选严格检查 `domain_bounds_constraint`，不借几何容差放宽范围，不静默扩大背景。输入缺少声明边界时，独立优化锁定其初始包围盒。

box/sphere 尺寸源可作用于上述所有阶段。历史 CAD 距离、曲率、间隙等尺寸源仅允许 `apply_to: background`；表面/过渡后端遇到其他源会明确拒绝。区域加密示例：

```json
{
  "id": "wake",
  "kind": "box",
  "apply_to": "all",
  "target_size": 0.08,
  "transition_width": 0.2,
  "region": {
    "bounds": {
      "minimum": [0.2, -0.4, -0.5],
      "maximum": [1.6, 0.4, 0.5]
    }
  }
}
```

## 边界层

显式指定目标 wall 物理组，每组可使用不同的层参数。第 i 层高度为 `first_layer × growth_ratio^i`，i 从 0 开始；总厚度为各层之和。增长率为 1 时总厚度等于首层高度乘层数。

```json
{
  "enabled": true,
  "strict_coverage": true,
  "targets": [
    {"group": "body_wall", "first_layer": 0.02, "count": 3, "growth_ratio": 1.2}
  ]
}
```

`first_layer` 表示壁面到第一层偏移面的法向厚度。它不是第一排单元中心到壁面的距离：三棱柱/四面体剖分会改变单元中心位置。以 y+ 设计近壁网格时，应根据生成后实际单元中心的壁面距离核对，不能把首层带厚度直接当作该距离。

首层高度必须为正，层数为 1–256，增长率须 ≥ 1。二维目标必须覆盖完整闭合边界环；三维目标必须覆盖完整闭合壁面壳。当前未实现局部层带的终止、相交层合并及复杂尖角自动截断，相关请求明确失败。报告给出层数、总厚度、法向高度的 min/max/p95 相对误差以及覆盖。

二维层带三角形挤出为三棱柱；三维层带按一致规则剖分为四面体。指定法向层高、正体积和可用间隙分别检查。当前间隙检查沿偏移路径采样，尚未提供全局体单元交叠扫描。层带失败不会静默减少层数或首层高度。薄层要求和曲面切向尺寸差距过大时，即使拓扑合法也可能不满足当前面质量门槛。

## 自动优化与验收

| 参数 | 含义 |
|---|---|
| `optimization.enabled` | 默认 true，可关闭 |
| `optimization.iterations` | 最大优化轮数 1–30，默认 6 |
| `optimization.relaxation` | 初始移动系数 (0,1]，默认 0.5；失败时缩小步长 |
| `optimization.topology_swaps` | 默认 true；三维过渡四面体的 3→2、4→4 内部换边，保持空腔外表面和节点；至多 min(256, iterations×32) 次完整候选检查 |
| `optimization.merge_transition_cells` | 默认 false；三维可尝试将相邻过渡四面体合并为真实凸多面体 |
| `optimization.max_merge_fraction` | 0–0.1，默认 0.1；接受的合并数不超过初始单元数的该比例 |
| `optimization.max_cell_growth_fraction` | 允许 0–0.05；节点移动或可选凸多面体合并，实际新增单元恒为 0 |
| `resources.max_cells` | 正值；背景构造、加密及生成结果受单元预算约束 |
| `resources.max_memory_mb` | 正值；背景预估与阶段间峰值 RSS 检查，属于预算检查，并非操作系统硬限制 |
| `resources.threads` | Gmsh 工作线程数，正整数 |
| `quality.mode` | strict：面质量失败则不导出；diagnostic：可导出拓扑合法的诊断网格 |
| `quality.max_surface_deviation_m` | 双向采样 CAD 距离容差；几何失败在两种模式下均拒绝 |

优化固定背景、物理边界和边界层点，只移动过渡区自由点；二维前后节点成对移动。尝试邻接平滑、三维四面体外心及面中心对齐目标，验证正体积和凸壳，用质量回滚约束 max/p99 非正交角及内部偏斜均不恶化。三维质量仍不达标时，最多再尝试 32 个自由节点组的局部面中心对齐。目标函数包含四项 max/p99 指标和全体面的四次方平均惩罚，使尚未改变最差面位置的局部改善也可被接受。可选合并只作用于过渡四面体，不合并背景或边界层；合并后的真实多面体必须保持凸性、正体积和原物理边界，四项面指标均不恶化。无法改善时保持原网格。报告记录优化前后指标、接受轮数、移动节点数、合并数及新增单元数。

当前面质量门槛为：最大非正交角 ≤ 75°，p99 ≤ 60°；最大内部归一化偏斜 ≤ 0.5，p99 ≤ 0.25。计算采用真实面积加权面中心和体积单元中心，并通过相邻 BabelSim reader 的几何计算交叉核对。单元质量、全局交叠和历史 profile 的其他指标尚未全部实现，报告始终保留 `full_cfd_profile_evaluated: false`。通过这些门槛不能单独证明 CFD 精度。

CAD 误差检查是双向采样到精确 B-Rep 的距离，不是连续 Hausdorff 上界证明。三维表面尺寸不够时最多自动缩小 4 次，每次乘 0.7，同时保持过渡尺寸；不突破 minimum_size，并记录调整次数。严苛容差可能增加表面/层单元，应先选择适合实际几何和物理尺度的尺寸。

## 命令行和图形调用

三维默认启用的局部换边只处理完整过渡四面体空腔，保持皮肤、节点和体积；成功后重建邻接并至多再平滑两轮。不会修改层带或笛卡尔连接。报告中的 `region_face_quality` 将跨区域接口计入两侧，`tetrahedron_shape_quality` 增加均比诊断。论文依据和对应限制见 [高质量混合网格论文与实现](高质量混合网格论文与实现.md)。

```bash
build/qt/bin/babelmesh generate examples/cylinder2d.json --out outputs/cylinder2d
build/qt/bin/babelmesh check outputs/cylinder2d/mesh.json
build/qt/bin/babelmesh optimize outputs/cylinder2d/mesh.json --out outputs/optimized --iterations 8
build/qt/bin/babelmesh-gui examples/cylinder2d.json
```

默认保护已有输出。显式 `--overwrite` 或 `output.overwrite: true` 才覆盖。生成在临时目录完成写入后发布；参数、拓扑、几何或严格质量失败不会发布新的结果。Qt 使用同一 CLI 生成核心，后台任务可取消。保存的工程快照与结果一同输出，便于复现。

Qt 顶栏可切换正交/透视、磨砂/实体材质和不透明度，单元边为黑色实线，隐藏面的边由深度检查遮挡。三维“网格结果”提供真实平面剖切与整单元筛选、X/Y/Z 轴和位置。平面剖切生成共面截面，关闭显示收缩；完整单元显示间隙只是视图效果，不改网格坐标。三维实体壁面使用中性色区分，以便识别空腔。

网格的检查点 `mesh.json` 保留生成维数、区域标签、层与 CAD 报告，是继续优化的首选输入。`mesh.bsm` 只含求解器需要的面拓扑和边界，未包含背景/层区域或生成维数。原生文件重新读入后，会标记区域保护信息缺失；优化器严格识别轴对齐盒状单元（包括粗细连接的分面多面体），并在缺失区域标签时保留全部节点及单元，仅检查和报告。具有完整 front/back 对称盖面、恰好两个轴向平面且每个单元节点精确成对的网格会恢复单层二维挤出规则。这些几何推断不会恢复首层高度、层数或边界层区域标签；需要执行保持边界层参数的节点优化时，应使用检查点。无 BabelMesh 自定义区域信息的外部 Fluent/CGNS 文件采用相同保护策略，元数据缺失状态也会通过本工具的交换输出传递。

## 格式转换范围

本工具 Fluent/CGNS 输出在自定义元数据中保留固定生成域。读取外部文件时不能保证原软件保留了这些元数据。`--length-scale` 为显式正比例单位/坐标缩放，同时缩放锁定边界和厚度，再检查；不会自动调整范围以容纳越界点。非单位缩放不会重新运行 CAD/层高生成审计，检查点中的相关生成记录仍属于源网格历史；实际转换记录和面几何报告单独给出。

```bash
build/qt/bin/babelmesh convert INPUT --to FORMAT --out OUTPUT \
  --from auto --length-scale 1 --checkpoint IMPORTED.json
```

| 格式 | 输入 | 输出 | 范围 |
|---|---|---|---|
| BabelSim v3 | 是 | 是 | 任意面环、owner/neighbour/patch；推断标准单元或保留多面体 |
| BabelMesh checkpoint | 是 | 是 | 实际混合连接与元数据 |
| Fluent ASCII | 是 | 是 | 三维面网格、混合标准单元与多面体、面区物理名；按文件 c0 面方向转换 |
| CGNS | 是 | 是 | 单一非结构 3D zone；一阶标准混合单元，或 NGON+有符号 NFACE |
| VTU | 否 | 是 | 标准混合单元及真实多面体面流，用于视图/后处理 |

输出格式名为 `babelsim-v3/checkpoint/fluent-ascii/cgns/cgns-poly/vtu`。`cgns` 遇到多面体会写 NGON/NFACE；`cgns-poly` 强制采用面拓扑。边界写 FaceCenter BC 与面 ID。读取 CGNS 声明的长度单位并归一化为米；Fluent ASCII 默认坐标为米，必要时显式 `--length-scale 0.001` 处理毫米文件。转换的缩放因子作用于导入后坐标，不应对已声明毫米单位的 CGNS 再重复缩放。

转换不添加单元，只转换坐标、连接、边界名和基本 patch kind；不转换材料、物理模型、求解设置、场数据。BabelMesh 自己写出的交换文件带有可选生成元数据，商业软件可能不保留这些自定义描述。Fluent 中无法直接表示的 generic patch 写入 wall 占位区，使用原软件时须设置实际边界条件。

边界名须能作为 BabelSim 单词写入，含空白的名称须先在原软件重命名。不支持 Fluent binary/HDF5、原生平面 2D、多区/结构 CGNS、overset/周期连接、高阶单元、只有 NGON 而缺 NFACE 的体网格、按点列出的 CGNS BC。当前不会猜测这些连接。STAR-CCM+ 和 FINE/Marine 的 `.ccm/.sim/.hex/.igg` 原生数据库尚未实现；可从原软件导出当前支持的体网格交换文件，再转换。已执行格式往返与独立 CGNS 检查，尚未在最新商业软件内验收导入。

参考实现依据：[Gmsh 官方手册](https://gmsh.info/doc/texinfo/)、[CGNS 多边形单元接口](https://cgns.org/cgns-archives/CGNS_docs_current/midlevel/grid.html)、[Fluent ASCII 文件格式](https://ansyshelp.ansys.com/public/Views/Secured/corp/v251/en/flu_ug/flu_ug_app_form_case_data.html)。
