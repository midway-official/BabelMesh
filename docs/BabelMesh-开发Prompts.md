本文件创建于 2026-09-23，提供分阶段开发要求和可执行验收标准；prompt 本身不构成实现或通过证据。当前实现和 gate 状态以 [acceptance/suite.json](/home/midway/BabelMesh/acceptance/suite.json) 与可重放测试为准。每阶段通过后再进入下一阶段；若明确要求连续实施，可串行执行 M0–M8，但每阶段验收不可跳过。

## M0：冻结输入输出契约、测试基准和构建结构

```text
执行 M0；当前阶段允许创建工程骨架、文档、schema和测试框架，不实现网格算法。

   检查凸面固定扇形对共线中点的退化风险及面积容差的绝对尺度下限，
   固化实际可读坐标/薄层尺寸范围和导出预检要求。
2. 建立 GNU Make 管理的 C++17 core library+CLI+contract-test 结构，提供 debug/release/test/clean/deps 目标。
   明确 geometry/sizing/cartesian/topology/snapping/layers/quality/io/integration 模块边界。
   几何代码禁用fast-math；锁定能在本机安装/编译的依赖版本和许可证清单。
3. 定义带版本JSON工程schema：units、CAD operations/import、fluid domain/seeds、
   physical groups、background、size controls、layers、quality、resource limits、output。
   禁止未知配置键静默忽略；给出重复标签、无seed、错误单位、超限预算等错误路径。
4. 冻结 inspect-cad/generate/check/export/verify-suite CLI和退出码。
   check可核验checkpoint；export只允许已通过指定profile的checkpoint。
   未实现子命令明确返回失败，不能返回成功placeholder。
5. 编写 acceptance/suite.json 和 quality profile，采用规划中的初始阈值。
   为M1–M8列出输入、期望几何、误差定义、资源预算、产物与pass/fail字段。
   各种报告都带schema_version，失败和重试可追踪。

验收：从干净build目录使用GNU Make编译并通过contract-test；schema正反例均正确；
```

## M3：局部区域加密与无裂缝粗细接口

```text
执行 M3。在M2背景网格上实现稀疏octree forest、1->8细分和2:1平衡。
实现box/sphere/cylinder、命名CAD面/边组、精确CAD距离带、曲率及双CAD组间隙尺寸源，小尺寸优先。`cad_group` 默认只加密与所选CAD实体相交的单元；`distance` 按 `region.distance` 加密距离带；`curvature` 只处理曲率半径不大于 `target_size` 的面；`gap` 要求 `cad_group` 与 `other_cad_group`，对同时落在两个组距离带内的单元加密。曲率采样精度必须写入报告，并用球面、圆柱面、平面和局部高曲率几何验证。
区域查询检测与cell包围体交叠，不能只检查中心而漏掉薄带。
实现最大层级/最小尺寸/maxCells/内存预算与超限失败。

实现粗细face覆盖细分及邻面边环传播，真正共享face ID；
一个粗面对应4细面时，粗cell引用4个子面并同步其侧面边段。
面环内允许必要共线点，所有单元逐边配对、面积向量闭合。
但BabelSim凸面扇形三角化可能对这些共线点生成退化三角形。
必须预检其实际三角化，必要时全局共享地拆成非退化三角面；
凸平面可用内部面心连接每条边段。不得删中点破坏边段配对。
禁止保留一份大面加四份重叠小面或以坐标近似重合代替拓扑一致。

强制测试：
1. 单独一个粗cell邻接4个细cell的接口。
2. 局部加密同时接触面/边/角，多root跨界，至少连续3层。
3. 薄尺寸带不含任何初始cell中心，但与cell相交，必须触发加密。
4. sphere、CAD面组、CAD边距离、曲率、两CAD组间隙，记录每个尺寸源的生效单元；平面曲率源应给出可诊断的无适用曲面错误。
5. 静止封闭box总体积误差<=1e-12；0裂缝/重复面/孤立点引用，原生reader通过。
6. 预算不足必须失败并报告未满足的尺寸源，不能输出“成功的粗网格”。

输出带level/source/cell type标记的VTK和粗细接口局部图，自动assert为主要验收。CAD几何只用于尺寸源时不得谎称已完成贴体或流体域裁切。
粗细过渡cell不符合严格六面体拓扑时如实标为polyhedron。
```

## M4：流体域提取、特征贴体与质量回滚

```text
执行 M4。使用M1 CAD/BVH与M3网格，实现inside/outside/intersect/uncertain判定，
在充分细化后形成可贴体阶梯边界；从fluid seed按被几何阻断的邻接提取流体区域。
以项目`sizing.surface_size`控制CAD交切区细化；开发期用`babelmesh generate PROJECT.json --cad-staircase`显式调用，

实现边界点与CAD face/edge/vertex关联，薄壁两侧不能投到同一表面。
先捕捉特征，再分步投影，内部用弹性或加权Laplace位移传播。
每步运行质量门禁和步长搜索，失败回滚；必要时局部细化并重新生成受影响区域。
锐边/交线需要局部拓扑处理，不能承诺仅点位移能解决全部特征。

对强翘曲共享面统一三角化时，两侧必须复用同一三角化。
验证面内几何误差，而不是只看顶点在CAD上。
失败诊断包括实体ID、CAD关联、几何偏差、非正交角及回退次数。

验收：轴对齐box、旋转30度box、sphere、cylinder、圆角台阶、有限厚尾缘、
夹缝和外包域减物体，全部真实三维。保持预期流体连通性和patch分组。
按锁定profile检查0非法单元，非正交max<=75/p99<=60度，
内部skew max<=0.5/p99<=0.25，双向采样误差满足eps_geom。
sphere/cylinder三档表面分辨率下体积与曲面逼近误差应下降，
中档体积相对误差起始要求<=0.5%，不能用粗糙阶梯网格通过。
所有合格网格通过实际BabelSim reader；不足者作为明确失败，不记为完成。
```

## M5：基本边界层与核心网格空间协调

```text
执行 M5，在平行板及光滑圆柱壁实现统一层数边界层。

支持r=1；明确t1不同于cell中心壁距，若接收y+必须记录u_tau依据。

真实壁面保持在CAD上，把核心边界向流体内部移到层顶并传播内部位移，
在壁面与层顶之间插入层柱。内流/外流分别确认流体侧方向。
层顶面和核心面为同一拓扑对象；相邻层柱共享侧面。
四边形基面用hex层，三角形基面用prism层，不能输出重叠体积。
这一阶段遇到不支持的尖角或局部终止明确拒绝，不允许默默不加层。

验收：
- 高度1平行通道，上下壁各10层，t1=0.002，r=1.2；剩余核心空间严格为正。
- 光滑圆柱外流壁，同样使用预先锁定的10层参数和可容纳的外域。
- 请求壁面完整10层面积覆盖100%，首层误差p95<=10%、max<=20%。
- 所有层厚沿真实壁法向测量；增长率最大<=1.3；测量首层中心壁距另列。
- 0穿层、0负体积、0裂缝；总流体体积不因插层改变，
  相对插层前同一封闭表面体积差<=1e-10。
- 通过质量profile与BabelSim真实reader，并检查层顶法向尺度跳变。
```

## M8：真实求解集成、自动验收与性能发布

```text
执行 M8，在保持BabelSim只读的前提下完成可复现发布验收。
建立verify-suite，逐项检查几何、拓扑、质量、边界层、格式、数值及性能。
任何required项失败都应使总退出码非零，报告完整结果而不是只打印passed项。

1. 对M1–M7基准重放，检查来源/hash、尺寸规则、patch及质量。
2. 用实际BabelSim公共API做常数场、线性场、共享面通量守恒，
   特别检查粗细界面及相同cell对多子面的装配行为。
3. 3D box Poisson制造解，三档尺寸比2，固定离散及边界，
   体积加权L2误差下降，后两档观测阶>=1.5。
   线性容差收紧10倍使误差变化<1%；局部加密网格另做成族误差研究。
4. 平行板Poiseuille带BL，细网格速度相对L2<=1%，
   进出口归一化流量不平衡<=1e-6，三网格误差递减。
5. 同一网格MPI 1/2/4 ranks按global cell对齐，
   无量纲场/积分差异目标<=1e-7，记录求解容差和自然退出状态。
6. 工程STEP案例自然完成受限流动冒烟，字段有限、无线性失败，
   明确物理模型和残差门限，不声称未经实施的VOF/船阻物理验证。
```
